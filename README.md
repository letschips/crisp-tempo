## 🌟 特色功能 (Highlights)

### 1. Things 3 的轻盈优雅 × Linear 的严密节奏
- **经典 GTD 视图矩阵**：内置收集箱（Inbox）、今天（Today）、接下来（Upcoming）、随时可做（Anytime）、将来也许（Someday）、等待依赖（Waiting）与已完成（Logbook，含已取消任务）。
- **敏捷周期（Cycles / Sprints）**：引入现代开发流的周/双周敏捷周期管理，自动识别当前活跃周期，支持周期范围排期校验。
- **项目管理**：侧栏列出全部项目（Projects）及完成百分比，可随时改名、换色或删除（删除时任务保留）。

### 2. 键盘优先与极速心流 (Keyboard-First Flow)
- **快捷键全局咬合**：
  - `⌘ + Enter` 或 `Enter`：极速提交新任务并保留编辑节奏。
  - `⌘ + Z`：完整的快照级事务撤销系统，新建、编辑、重置均可一键回滚。
  - `Esc`：秒级退出编辑与关闭弹出层。
  - 方向键 `↑ / ↓`：在待办列表间无缝穿梭聚焦。
- **macOS 原生毛玻璃质感**：沉浸式半透明高光边缘与圆角卡片，完美咬合 Obsidian 官方暗色与亮色主题。

### 3. 子任务与进度追踪 (Hierarchy & Progress)
- **多层级任务树**：支持为任意任务拆分子任务，即时计算父任务与项目的完成度。
- **属性检视抽屉**：独立 Inspector 侧边面板，快速调整状态、优先级、所属项目、规划时期、所属周期与截止日期，并管理子任务。
- **预计用时与每日可用时间**：任务详情里填「预计用时」（分钟），设置里填「每日可用时间」。「今天」列表顶部显示已安排多少分钟、还有几项没估时，超出可用时间时标出超了多少。已完成的计入，已取消的不计。子任务填了用时的，父任务按子任务逐层合计（不再加上自己的数），没填的子任务计入「未估时」；一个子任务都没填时，父任务自己的用时代表整件事。
- **计划开始与截止分开**：任务详情和新建任务里可以选「计划开始」。开始日在以后的任务进入「接下来」，到那天自动回到「今天」；截止日期只表示最晚完成的日子。在「规划时期」里改回收集箱、今天、随时可做或将来也许，会清掉计划开始日。
- **子任务**：标题可以直接改，每个子任务可以填预计用时，父任务按子任务合计。
- **列表行**：显示 Crisp Focus 正在计时的任务、预计用时和下一步；窄面板和手机上只显示专注状态。
- **下一步与成果**：任务详情里可以写「下一步」，以及一个「成果」（笔记名、`[[双链]]` 或网址），点「打开」直接跳过去；笔记找不到时会提示，不会新建空白笔记。

### 4. 100% 本地优先与隐私安全 (Local-First & Zero-Telemetry)
- **干净空白初态**：全新安装开箱即用，默认创建纯净的空白数据库，绝不携带任何测试数据或隐私残留。
- **标准 JSON 存储**：所有数据均存储在 `.obsidian/plugins/crisp-tempo/data.json` 中，结构清晰，可随时通过外部脚本审计。
- **同步后自动刷新与合并**：`data.json` 被同步服务或其他设备改动后，打开的看板直接换成新内容，不用重开。这台设备还有没保存的改动时，保存前按任务合并两边的改动；两边改了同一个任务时保留这台设备的版本，另一台的版本先存成 `data.json.conflict-日期-时间` 副本并提示。合并只在一台设备的一次保存里完成，不能代替同步服务本身的冲突处理。
- **防丢自愈快照**：插件启动时自动生成每日快照（`data.json.bak-YYYYMMDD`），支持设置面板一键导出完整备份到库内指定目录。

### 5. 与 Crisp Pulse 速记联动
- 装了 Crisp Pulse 1.16.0 或更高版本时，速记卡片菜单里可以「转为 Tempo 任务」：任务进默认目的地（收集箱或今天），标题取速记第一句，全文放进详细描述。一条速记只对应一条任务。
- 任务详情的「来源」显示它来自哪条速记，点一下打开那篇笔记；速记卡片上能看到任务的状态，点一下回到 Tempo 中的这条任务。
- 装了 Crisp Pulse 1.29.0 或更高版本时，在 Tempo 里每完成一个任务，Pulse 看板底部的湖面会升起一盏孔明灯。
- 装了 Crisp Pulse 1.35.0 或更高版本时，Pulse 每天的明细里会列出当天在 Tempo 完成的任务，点任务名回到 Tempo。只是列出，不计入 Pulse 的「完成任务」和贡献分。

### 6. 与 Crisp Focus 专注联动
- 装了 Crisp Focus 1.7.0 或更高版本时，任务详情里有「专注」一栏：可以「开始番茄」（需 Focus 激活，整轮番茄都记在这个任务上）或「单次专注」（时长按 Focus 设置）。
- 每段专注结束后记在任务上：完成的按计划时长，中途结束的按实际专注分钟，不足 1 分钟的不记。详情里显示累计时长和完成、中断的段数。
- 正在为这个任务计时时显示当前状态，可直接打开番茄钟；Focus 正在为别的任务计时，在这里开始会把那段按原任务记为中断。
- 计时由 Focus 负责，记录保存在 Tempo 的 `data.json` 里。没装 Focus 时这一栏不出现。
- 一段专注结束后，看板顶部出现一行可以直接写「下一步」的提示，不填、关掉都不影响任何东西。
- 装了 Crisp Focus 1.9.0 或更高版本时，Tempo 停用、重载或保存失败期间结束的专注，会在 Tempo 启动时或下一段专注结束后按 Focus 的会话日志补记（Focus 保留最近 300 段），同一段只记一次。更早的 Focus 版本没有日志，停用期间的专注不会补记。

### 7. macOS 提醒事项与日历
- 仅限 macOS 桌面版。在 Tempo 设置的「提醒事项与日历」里打开，第一次打开时系统会请求 Obsidian 访问提醒事项或日历的权限；拒绝后可以点「打开系统设置」再允许。
- **提醒事项**：所选列表里未完成的提醒会变成 Tempo 任务（第一次打开默认选系统的默认列表）。有截止日期的按日期出现在「今天」或「接下来」；没有截止日期的放进「默认目的地」（收集箱或今天），和快速新建的任务一样。已关联的任务和提醒同步标题、备注（任务的详细描述）、截止日期和完成状态：只有一边改了取那一边，两边都改了取后改的；任务取消也会把提醒标为完成。提醒带具体时间的，Tempo 只记日期，改日期时保留原来的时间。
- 任务详情里可以「添加到提醒事项」（放进设置里选的列表，没选就用系统默认列表），已关联的显示列表名，可以「取消关联」：两边各自保留、不再同步，那条提醒也不会再被导入成新任务。之后再点「添加到提醒事项」，原来那条提醒还没完成就重新关联它，不另建一条；已完成或删掉了才新建。
- 两台设备同时导入同一条提醒、出现两个任务时，Tempo 会提示一次，只让较早的那个继续同步；另一个任务详情里写着「和「…」是同一条提醒」，可以「打开那条」比对后删掉不要的，Tempo 不会自动删除。在 Tempo 删除任务不会删除提醒，那条提醒也不会再被导入；在提醒事项里删除提醒，Tempo 的任务保留、只解除关联。
- 设置里打开「新建任务自动添加到提醒事项」后，之后新建的任务（含手机上新建、Pulse 速记转来的，不含子任务和从提醒事项导入的）会在下一次同步时自动放进提醒事项，用的是「添加到提醒事项时放进」选的列表；打开前已有的任务不受影响。取消关联、或在提醒事项里删掉那条提醒后，这个任务不会被再次自动添加。
- 写回提醒前会核对提醒是否在读取后又被改过（比如刚在手机上改），改过就先不写，下一轮按后改的一边合并。
- 导入列表可以全部不勾，这时只同步已关联的任务；关掉再打开也不会自动选回默认列表。
- 同步时机：提醒事项或日历一有变化（在提醒 App 里改、或从 iPhone 经 iCloud 同步过来）约 1 秒内同步到 Tempo；Tempo 里改了已关联的任务约 1 秒后写回。另外启动时、每 5 分钟、Obsidian 回到前台时也会补一次，设置里也可以点「立即同步」。iPhone 上的改动多久到达这台 Mac 取决于 iCloud。手机上照常编辑，Mac 上的 Tempo 下次同步时写入提醒事项。
- 导入新提醒需要激活 Tempo；已关联的任务不受影响。
- **日历**：「今天」顶部列出当天日程（只读），有具体时间的日程计入每日可用时间，重叠的只算一次；全天、标为空闲和已取消（划线显示）的日程不占时间。日程没能刷新时保留之前读到的并标「未能更新」。可以选显示哪些日历。
- 读写由插件自带的小程序 `tempo-apple-helper`（源码在 `native/`）通过系统 EventKit 完成，第一次使用时写到插件目录；只在本机读写，不联网。打开提醒事项或日历期间它常驻运行（约 20MB 内存，空闲不占 CPU），关掉两项或停用插件时退出。

### 8. Crisp Suite 家族无感激活 (License)
- **同门插件自动继承**：若保险库中已安装并激活其他 Crisp 插件（如 Crisp Mind、Crisp Pulse 等），Crisp Tempo 会在启动时自动发现并无缝继承全家桶授权。
- **离线密码学验证**：内置 Ed25519 嵌入公钥，授权码先在本地验签。激活时、以及每次启动加载任务数据时，会在后台联网核对一次吊销状态与设备数，服务端明确拒绝时授权失效；网络不可用、请求超时（2.5 秒）或服务暂不可用时自动降级为本地验签，不影响使用。
- **激活范围**：未激活时可以查看、编辑、完成、删除和导出已有任务；新建任务、子任务和项目需要激活码。

## 🚀 安装方式 (Installation)

### 方式 1：通过 BRAT 插件安装（推荐）
1. 在 Obsidian 中安装并启用 **Obsidian42 - BRAT** 插件。
2. 打开命令面板（`⌘ + P`），搜索并选择 `BRAT: Add a beta plugin for testing`。
3. 输入本仓库地址：`letschips/crisp-tempo`。
4. 点击 `Add Plugin`，安装完成后在“第三方插件”列表中启用 **Crisp Tempo** 即可。

### 方式 2：手动下载安装
1. 前往本仓库的 [Releases](https://github.com/letschips/crisp-tempo/releases) 页面，下载最新的发行包文件：
   - `manifest.json`
   - `main.js`
   - `styles.css`
2. 在您的 Obsidian 保险库目录中，进入 `.obsidian/plugins/`，新建文件夹 `crisp-tempo`。
3. 将下载的 3 个文件复制到 `crisp-tempo` 文件夹中。
4. 重启 Obsidian 或在设置中重新加载插件，启用 **Crisp Tempo**。
